ปัญหาที่เจอ & วิธีแก้

1

Google Maps field names เปลี่ยน

Apify actor คืน field names ต่างจาก schema ที่วางไว้ ทำให้ columns ใน Sheets หัวตาราง mismatch

✅ แก้: re-map column headers ใน clean data phase + เพิ่ม column validation

2

Eatigo ไม่มีข้อมูล priceLevel

Browse AI scrape จาก Eatigo ได้ rating และ review count แต่ไม่มีช่วงราคา ทำให้ scoring ด้าน Price ไม่สมบูรณ์

✅ แก้: ใส่ "Needs verification" และให้ Price Score = 5 แทน 0 เพื่อไม่ penalize เกินไป

3

n8n rate limiting เมื่อรันหลาย workflow พร้อมกัน

การรัน 5 ย่านพร้อมกันทำให้ Google Sheets API rate limit → rows ไม่ถูก append ครบ

✅ แก้: รันทีละย่าน รอ 2-3 นาทีก่อน trigger ย่านต่อไป

4

Gemini เลือก Top 3 เองแทนที่จะอธิบาย

Node 8b เดิมให้ Gemini เลือก Top 3 เอง ทำให้ผลต่างจาก scoring model ที่คำนวณไว้

✅ แก้: เปลี่ยน prompt บอก Gemini ว่า Top 3 คือใครแล้ว ให้แค่เขียนเหตุผล

5

Apify credits หมด กลางโปรเจกต์

Account เดิม credit เหลือน้อยหลังจาก scrape หลายรอบ ทำให้ workflow หยุดกลางคัน

✅ แก้: สร้าง Apify account ใหม่ + อัปเดต credential ใน n8n ทุก workflow
